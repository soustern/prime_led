# Prime LED - Company Website

A modern and responsive single-page website developed for Prime LED, a company specializing in high-quality LED products. This project serves as a digital presence for the company, showcasing its services, products, and contact information in a clean, professional, and visually appealing format.

### ✨ [View the Live Demo](https://soustern.github.io/prime_led/)


## Key Features

*   **Responsive Design:** A mobile-first approach ensures the website looks and functions perfectly on all devices, from mobile phones to desktops.
*   **Smooth Scroll Animations:** Subtle, on-scroll animations are implemented to dynamically reveal content, creating an engaging user experience.
*   **Clear Call-to-Actions:** Strategically placed contact information and social media links make it easy for potential clients to get in touch.
*   **Organized Sections:** The single-page layout is divided into intuitive sections: About, Products, Gallery, and Contact.
*   **Optimized Assets:** The code and assets are structured for clean readability and efficient loading.

## Tech Stack

This website was built using fundamental front-end technologies with a focus on maintainability and performance.

*   **HTML5:** Semantic HTML for a structured and accessible website.
*   **CSS3 (with SASS):** Advanced styling using SASS as a preprocessor for modular and reusable code (e.g., variables, nesting, partials).
*   **JavaScript:** Used for dynamic functionalities, including the scroll-reveal animations and interactive navigation.
*   **NPM:** Utilized as a package manager for development dependencies.

## Project Structure

The codebase is organized with a clear and scalable structure, separating logic, styles, and assets.
